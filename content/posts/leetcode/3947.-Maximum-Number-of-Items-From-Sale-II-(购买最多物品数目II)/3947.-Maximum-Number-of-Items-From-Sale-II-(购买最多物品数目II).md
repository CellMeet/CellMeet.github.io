# 3947. Maximum Number of Items From Sale II (购买最多物品数目II)

题目链接: [Maximum Number of Items From Sale II](https://leetcode.cn/problems/maximum-number-of-items-from-sale-ii/?envType=daily-question&envId=2026-11-28)

思路和昨天的每日一题一样, 只不过这次是"买一赠一", 而不是"买一赠多"

## 题目理解

intput:

```python
items = [[1, 6], [2, 4], [3, 5]]
budget = 19
```

购买一个[1, 8],  赠送一个[2, 4], 再购买一个[1, 6], 赠送一个[3, 5].

对与一个i, 统计满足factor[j] 是factor[i] 的倍数的物品j 的个数, 记作cnt[i], 那么:



所以买一赠一怎么是最优解?

都是买一赠一, 肯定去最便宜的,

- 对于价格 < min_price * 2 的物品, 先购买cnt 次数, 然后每次从低到高购买

- 对于价格 >= min_price * 2 的物品, 从不购买.

## 赠送次数高效计算

- 方法一: 暴力枚举

  对于每个物品`i`, 遍历其他物品`j` :

  ```python
  gain = [0] * n
  for i in range(n):
      for j in range(n):
          if i != j and items[j][0] % itmes[i][0] == 0:
              gain[i] += 1
  ```

- 方法二: 枚举倍数:

  假如我们有以下因子:

  ```python
  factors = [1, 2, 2, 3, 4, 6]
  ```

  

  统计每个因子出现的次数, 

  ```python
  [1: 1, 2: 2, 3: 1, 4: 1, 5: 0, 6: 1]
  ```

  这样不需要遍历所有的物品, 而是枚举 2 的倍数 `2, 4, 6, 8 ...` :

  相加, 减去自己(-1), 得到:

  `2 + 1 + 1 (- 1) = 3 `

  对应的代码:

  ```python
  for f in range(1, mx + 1):
      gain[f] = -1
      
      for j in range(f, mx+1, f):
          gain[f] += cnt[j]
  ```

​			这样的话, 就需要一个保存 每个因子cnt 的数组

## 解题思路

- 首先, 代码要写好思路

  要明确思路:

  核心逻辑:

  如果一件商品的price < min_price * 2, 然后可以购买, 按照价格从低到高购买 cnt 次数

  所以每个商品的 factor 的关联次数 和 price  < min_price 就很重要, 这是input 的关键信息.

  1. 统计最小价格  和 每个factor出现的次数

     ```python
     n = len(items)
     cnt_factor = [0] * (n + 1)
     min_price = inf 
     for factor, price in items:
         cnt[factor] += 1
         min_price = min(min_price, price)
     ```

     

  2. 枚举倍数, 计算赠送的次数

     ```python
     cnt_multi = [0]* (n + 1)
     a = []
     for factor, price in items:
         if price >= min_price * 2
         	continue
         
         if cnt_multi[factor] == 0:
             for j in range(factor, n+1, factor):  # 这里是因为 factor_i <= items.length, 正确的想法是, 统计最大的factor
             	cnt_multi[factor] += cnt_factor[j]
         
         cnt = cnt_multi[factor] - 1
     ```

  3. 一个辅助数组, 如果一个item 的price < min_price * 2, 并且 它还有"赠送"的机会(`cnt > 0`), 那么可以先购买这里的物品, 加入候选项:

     ```python
     if cnt > 0:
         a.append((price, cnt))
     # 对a 进行排序, 价格低的优先
     a.sort(key = lambda x: x[0])
     ```

  4. 统计答案

     ```python	
     ans = 0
     for price, items in a:
         if budget < price: # 没钱了
             break
         c = min(cnt, budget // price)  # 该物品最多购买 c 个
         budget -= price * c
         ans += c * 2
         
     return ans + budget // min_price
     ```

  

  ## 代码

  

  ```python
  class Solution:
      def maximumSaleItems(self, items: List[List[int]], budget: int) -> int:
          # 最小price 和 最大factor
          mn_p = min(p for f, p in items)
          mx_f = max(f for f, p in items)
  
          # 找每个factor 的cnt
          cnt = [0] * (mx_f + 1)
          for f, p in items:
              cnt[f] += 1
  
          # 枚举倍数, 计算赠送次数
          gain = [0] * (mx_f + 1)
          for f in range(1, mx_f+1):
              if cnt[f] == 0:
                  continue
              gain[f] = -1
  
              for j in range(f, mx_f+1, f):
                  gain[f] += cnt[j]
          
          items.sort(key = lambda x: x[1])
  
          ans = 0
          # 贪心, 有限购买促销商品
          for f, p in items:
              if p > 2 * mn_p or p > budget:
                  break
              
              k = min(gain[f], budget // p)
  
              ans += 2 * k 
              budget -= k * p 
          
          ans += budget // mn_p
      
          return ans
  ```
